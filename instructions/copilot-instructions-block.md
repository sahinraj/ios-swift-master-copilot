## iOS / Swift project guidance

This repository is an Apple platform codebase using Swift, SwiftUI and SwiftData.

- Follow the rules in `.github/instructions/swift.instructions.md` for all Swift files.
- For detailed Swift, SwiftUI, SwiftData, concurrency, testing, accessibility and security guidance, use the `ios-swift-master` skill in `.github/skills/ios-swift-master/`. Read the matching file in its `references/` folder before large changes or reviews.
- For complex tasks, the `iOS Swift Master` custom agent in `.github/agents/` applies all of these rules.
- Match the existing architecture and conventions. Keep changes scoped to the task.
- Build and run tests after changes when tools allow it.
