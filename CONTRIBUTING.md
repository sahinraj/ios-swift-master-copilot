# Contributing

Contributions that improve accuracy, compatibility, or installation safety are welcome.

## Before opening a pull request

1. Keep guidance grounded in official Apple, Swift, GitHub, or Microsoft documentation.
2. Put topic-specific detail in the matching file under `skills/ios-swift-master/references/`.
3. Keep `SKILL.md` focused on routing and rules that apply broadly.
4. Run the checks:

   ```bash
   ./install.sh verify
   bash tests/install_test.sh
   ```

5. Explain which SDK and toolchain versions you verified.

Do not include proprietary source code, credentials, personal data, or copyrighted material copied from documentation.
